# BusCar

**Gerencie o transporte escolar como nunca antes!**

Está cansado de ter que ficar toda hora escrevendo quem são os alunos que irão buscar? Está cansado de ter uma caixa de surpresas todos os dias por falta de manutenção do veículo?
**A BusCar tem a __solução!__**

Na BusCar, você pode:
- Gerenciar sua frota de veículos de sua empresa;
- Gerenciar alunos cadastrados;
- Consultar endereços de alunos;
- Gerenciar motoristas registrados.

> [!NOTE]
> Atualmente, esse aplicativo é um projeto da disciplina de POO na Fatec
